# 🏘️ 土地法規．條文動畫與互動講義｜Land Law Interpretation

> 從「我家的地」開始，一條一條讀懂都市計畫法與土地徵收條例。

姊妹專案：[公平交易法教材](https://mjib007.github.io/fair-trade-law-interpretation/)、[刑法教材](https://mjib007.github.io/criminal-law-interpretation/)。

## 總覽頁

首頁以生活問題引導學習：

- **第一課**：我家的地被畫成公園？公共設施保留地，76秒動畫＋互動講義。
- **六個問題主題**：保留地、徵收程序、區段徵收、都市計畫變更、使用分區、徵收後收回；尚未提供的標示「後續課程」。
- **搜尋**：依主題、關鍵字或條號篩選。
- **依法條找教材**：都市計畫法九章、土地徵收條例六章，已有主題的章節可點選篩選。

## 每份教材包含

| 內容 | 說明 |
|---|---|
| 短影音 | 直式動畫，生活案例開場，台灣華語AI旁白與字幕 |
| 互動講義 | 條文原文逐句反白＋白話解釋、流程、自我練習 |
| 來源 | 條文以全國法規資料庫現行條文為準；大法官解釋附官方連結 |

條文版本：都市計畫法民國110年5月26日修正；土地徵收條例民國101年1月4日修正（全國法規資料庫，2026-10-30擷取）。
